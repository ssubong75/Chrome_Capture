저장 도우미 확인 중…

처음에는 ZIP에 포함된 저장 도우미 설치 파일을 실행하세요. 기본 폴더는 바탕화면의 Capture입니다.

오디오 녹음

저장 형식: MP3 · 스테레오 · 192kbps. 현재 탭의 소리만 녹음하며 마이크를 사용하지 않습니다. 녹음 중에도 소리를 들을 수 있습니다.

공통 폴더 저장에 실패하면 다운로드 / Chrome Capture에 대신 저장하고 팝업에 사유를 표시합니다.

화면 캡처

저장 형식: PNG. 팝업에서 지연 시간, 영상 자동 크롭, 자막·컨트롤 숨기기를 설정합니다.

단축키

녹음: Mac ⌘⇧7 / Windows Alt⇧7 · 화면 캡처: Mac ⌘⇧0 / Windows Alt⇧0

파일명

날짜_시간으로 자동 저장합니다. 예: 20261005_193951.mp3 / 20261005_193951.png. 같은 이름이 있으면 숫자를 붙여 기존 파일을 보존합니다.
