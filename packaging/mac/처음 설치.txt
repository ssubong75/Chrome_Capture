Chrome Capture — mac

1. ZIP을 풀고 폴더를 원하는 위치에 둡니다.
2. 저장 도우미 설치.command를 실행합니다.
3. Chrome에서 chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램을 로드.
4. 이 폴더의 chrome-extension을 선택합니다.
5. 설정에서 공통 저장 폴더를 선택합니다. MP3와 PNG가 같은 폴더에 저장됩니다.

오디오: MP3, 3초/5초, 기본 5초.
화면 캡처: PNG, 지연 0/1/3/5초, 자동 크롭·오버레이 숨김.
파일명: 261005_1939.mp3 / 261005_1939.png
Mac 단축키: 녹음 Command+Shift+7, 화면 Command+Shift+0.
Windows 단축키: 녹음 Alt+Shift+7, 화면 Alt+Shift+0.

기존 두 확장은 비활성화하고 단축키가 비어 있으면 chrome://extensions/shortcuts에서 등록하세요.
Mac은 Node.js가 필요합니다. Windows는 Python/Node.js 설치가 필요 없습니다.
상세 내용은 사용법.md에 있습니다.
