Chrome Capture — Getting Started (Mac)

1. ZIP을 풀고 Chrome Capture 폴더를 원하는 위치에 둡니다.
2. Mac에는 Node.js가 필요합니다. 설치 전 Node.js를 준비하세요.
3. install.command를 실행해 저장 도우미를 설치합니다.
4. Chrome에서 chrome://extensions → 개발자 모드를 켭니다.
5. 압축해제된 확장 프로그램을 로드 → 이 폴더의 chrome-extension을 선택합니다.
6. Chrome Capture 아이콘을 툴바에 고정하고 설정에서 공통 저장 폴더를 선택합니다.
   기본 저장 폴더는 바탕화면의 Capture이며, AAC-LC (M4A)와 PNG가 같은 폴더에 저장됩니다.

오디오: 현재 탭의 소리를 AAC-LC (M4A)로 녹음. 3초/5초, 기본 5초.
화면 캡처: PNG. 지연 0/1/3/5초, 영상 영역 자동 크롭·오버레이 숨김.
파일명: yymmdd_hhmm (컴퓨터의 현재 시각, 두 자리 연도, 초 제외).
예: 261005_1939.m4a / 261005_1939.png
중복 시: 261005_1939_1.png, 261005_1939_2.png처럼 번호를 붙이며 덮어쓰지 않습니다.
단축키: 녹음 Command+Shift+7 / 화면 캡처 Command+Shift+0.

설치 후 chrome-extension 폴더를 옮기거나 삭제하지 마세요.
이전 녹음·캡처 확장은 비활성화하고, 단축키가 비어 있으면 chrome://extensions/shortcuts에서 등록하세요.
확장 파일을 업데이트한 뒤에는 chrome://extensions에서 Chrome Capture의 새로고침 버튼을 누르세요.
제거: uninstall.command로 저장 도우미를 제거하고, Chrome 확장은 chrome://extensions에서 별도로 제거합니다.
자세한 내용은 User Guide.md를 읽어주세요.
